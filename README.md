# 拼豆小工坊

[在线试玩](https://zxl9456-hub.github.io/bead-workshop/)

基于 Three.js 的暖色拼豆小游戏。包含午后小猫、花园小兔、草莓、雏菊、小蛙、晴天小云、爱心、蝴蝶共 8 种图案，以及 24 × 24 的自由创作模式。

## 运行

不需要安装依赖，Three.js 已保存在 `vendor`。

```sh
python3 -m http.server 4173
```

浏览器访问 `http://localhost:4173`。不要直接双击 HTML 文件，ES 模块需要通过 HTTP 加载。

## 操作

- 点击颜色碗，再点击拼板放置豆粒；空位数字对应颜色编号。
- 原创 BGM「猫爪小调」会在第一次操作后开始循环播放。右上角音符可播放/暂停，设置里可调节音量；音乐开关和音量会自动保存。切到其他页面时暂停，回来后继续。
- 单颗：一次点击放一颗。连填：按住拖动，连续放置。橡皮：点击或拖动擦除。
- 撤销：一次撤回一整笔。重新开始可以清空当前图案，也可以撤销清空操作。
- 拼齐图案后，点击「熨烫 · 完成作品」收藏；自由创作可随时收藏。
- 「我的作品」可以查看和下载作品 PNG。
- 图案切换时会保留各自进度；刷新会恢复浏览器本地保存的进度、金币和作品。
- 滚轮或按钮缩放；鼠标右键拖动可调整立体视角；Shift + 拖动可平移；↺ 复位。
- 方向键移动拼板光标，空格或 Enter 放置；Q 单颗，W 连填，E 橡皮；1–9 选色；⌘ / Ctrl + Z 撤销。

游戏数据保存在当前浏览器的 localStorage，不提供跨设备同步。没有 WebGL 时自动切换为 Canvas 轻量拼板。

## 文件

- `index.html`：界面和对话框
- `style.css`：参考图风格的响应式界面
- `app.js`：Three.js 场景、交互、存档和作品导出
- `patterns.js`：图案、颜色和进度计算
- `bgm.js`：BGM 循环、淡入淡出、暂停和音量控制
- `assets/cat-paw-groove.mp3`：原创无歌词配乐，108 BPM，32 小节，约 71 秒
- `vendor/three.module.js`：Three.js r170
